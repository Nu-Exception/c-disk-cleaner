# Disk Cleaner v3

Windows 安全磁盘清理工具，作者：**CS**。

当前版本：**v3.9**

## 功能简介

Disk Cleaner v3 是一个基于 Python 的 Windows 控制台清理工具，主要用于扫描磁盘空间占用、清理缓存、删除空文件夹、管理软件卸载项，并提供基础的注册表保守清理提示。

## 主要功能

- 扫描磁盘大文件夹 / 大文件
- 扫描文件夹和文件明细
- 文件夹与文件分开显示
- 显示文件类型、大小、创建日期、修改日期
- 按序号清理扫描结果
- 支持进入某个文件夹继续扫描：`S序号`
- 支持打开扫描结果所在目录：`O序号`
- 扫描并清理缓存目录
- 常用缓存专项清理
- 删除空文件夹
- 软件卸载管理
- 注册表保守清理提示
- 显示电脑基础信息、磁盘信息、用户名、IP、显卡、WiFi 名称
- 支持字体颜色设置
- 自动生成日志到用户目录下的 `清理日志` 文件夹

## 使用方法

### 方式一：直接运行 Python 脚本

需要电脑已安装 Python 3。

```bash
python disk_cleaner_v3.py
```

### 方式二：双击 BAT 启动

双击：

```text
Disk_Cleaner_v3.bat
```

注意：BAT 启动方式仍然需要电脑已安装 Python。

### 方式三：打包成 EXE

双击：

```text
打包成EXE.bat
```

打包完成后生成：

```text
dist\DiskCleaner_v3.exe
```

把 `DiskCleaner_v3.exe` 发给别人即可运行，对方不需要安装 Python。

## 扫描结果操作说明

扫描结果显示后，可以输入以下命令：

```text
1          清理第 1 项
1,3,5      清理第 1、3、5 项
1-5        清理第 1 到第 5 项
S1         进入第 1 项文件夹继续扫描
O1         打开第 1 项所在目录
B          返回主菜单
N          不删除，返回
```

## 风险说明

工具会对扫描项目标记风险等级：

```text
low       低风险，一般是缓存、临时文件、日志等
medium    中风险，可能包含用户资料、软件配置、游戏文件等
high      高风险，可能包含系统文件、驱动、软件主体等
```

高风险项目默认禁止直接清理。中风险项目需要二次确认。

## 安全提醒

请不要随意删除以下内容：

- Windows 系统目录
- Program Files
- Program Files (x86)
- ProgramData
- Steam 游戏库主体目录
- 微信/QQ 文件目录
- 桌面、文档、图片、视频等个人资料目录
- Microsoft Visual C++、.NET、显卡驱动、声卡驱动、网卡驱动等系统组件

## 注册表清理说明

注册表清理功能为保守模式。使用前建议创建系统还原点。

本工具不会建议用户激进清理注册表，因为误删注册表可能导致软件异常或系统问题。
